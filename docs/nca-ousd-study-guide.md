# NCA OpenUSD Foundations and Workflows Study Guide

A study guide and practice workbook for the **NVIDIA Certified Associate: OpenUSD Foundations and Workflows (NCA-OUSD)** exam.

The guide covers 30 blueprint tasks across four domains, three supplemental topic groups, five worked workflow cases, and 24 formative practice questions with an explanation for every option. It teaches the concepts through instructional scenarios and does not reproduce operational exam questions.

```{attention}
This guide is based on a provisional exam blueprint. It is not an approved exam specification, an official passing standard, or a guarantee of readiness.
```

## What is covered

- **Domain 1 — OpenUSD fundamentals.** Stages, layers, prims and properties; attributes and relationships; file formats; represented data versus executing behavior; schemas; defaults and time samples; metadata.
- **Domain 2 — Composition and scene assembly.** Composition mechanisms, strength ordering, choosing arcs from requirements, references versus payloads, non-destructive collaboration, variant sets, and diagnosing a missing opinion.
- **Domain 3 — Workflow architecture.** Workstreams, workflow diagrams, naming, versioning, custom properties versus custom schemas, dependencies and handoffs, asset guidelines, and matching features to measured bottlenecks.
- **Domain 4 — OpenUSD value and ecosystem.** Stakeholder benefits, Hydra, visualization, tool compatibility, interoperability, large-scene scalability, adoption cases, and AOUSD.

## How to use it

Work through the recommended training path and the study lessons first, then answer the practice questions without reading the explanations. Each lesson check and practice answer links to a reading ID in the guide's reference register, so you can return to the source material for anything you cannot explain in your own words.

The [Learn OpenUSD curriculum](index.md) is the companion training for this material. Note that the curriculum is written for the development-focused certification, so its Python exercises are optional at the associate level.
